📦 Sistema de Gestão de Estoque e Vendas
Aplicação web moderna e funcional desenvolvida para simplificar o controlo de inventário, registo de fornecedores, gestão de produtos e acompanhamento de entradas e saídas financeiras.

🚀 Funcionalidades Principais
Painel de Controlo (Dashboard): Visualização rápida do saldo total, total de entradas, total de saídas, quantidade de lançamentos e produtos em stock.

Gestão de Stock & Produtos: Registo, edição e consulta de itens armazenados com controlo de quantidades.

Registo de Entradas e Saídas: Controlo financeiro de compras e vendas com categorização e valores.

Gestão de Fornecedores: Registo e organização dos contactos de fornecedores.

Relatórios: Emissão e visualização de resumos de movimentações e inventário.

Autenticação: Sistema de login seguro para controlo de acesso.

🛠️ Tecnologias Utilizadas
Backend: PHP

Armazenamento de Dados: JSON (db.json)

Frontend: HTML5, CSS3 (Design moderno com tema escuro/dark mode) e JavaScript
